# 有余

面向大学生的生活费规划与提醒应用。把当月生活费分到安全、体验、财富三个账户，手动记账、导入微信或支付宝账单，并为应急金、旅行等目标确认存入进度。账户是规划分类，不连接或操作真实资金。

## 当前版本

- 手机与电脑均可使用；首次打开可先试用演示账本。
- 支持安装到手机主屏幕。设置页提供安装入口；断网时显示重试页，不在设备离线缓存中保存账本或登录信息。
- 预算、记账、账单导入、储蓄目标与存入统一使用安全、体验、财富三个账户。默认比例为 50 / 30 / 20，可直接编辑百分比或金额，二者同步计算。
- 旧版六用途账本在读取时按“基本生活→安全；计划消费、自由消费、自我提升→体验；应急储蓄、长期积累→财富”合并，保留金额、记录与原始六用途分类供历史核对。
- 首页集中展示本月可用金额、三账户和最近记录。月份与记账日期使用应用内的选择器。
- 手机记账提供常用消费类别、金额快捷键与底部快捷入口，仍可手动修改说明、归属账户、日期和支付渠道。
- 登录后可建立自己的账本，记录按账号保存。
- 新增记录只提供支出和收入。旧版退款、转账记录仍保留供历史核对；导入时跳过转账和还款，退款作为带提示的收入记录。
- 支持 CSV 和 XLSX 账单文件的预览、分类核对、重复记录排除。用户需要先从支付应用导出并解压文件；原始文件在浏览器内读取。
- 支持目标存入与撤销、站内预算提醒、规划日和周回顾提醒。关闭页面后不发送系统推送。

## 本地运行

在 Windows 上可双击 `启动有余.cmd`。保持弹出的窗口打开即可使用本地版；关闭窗口会结束预览。

也可以进入此目录，在终端执行：

```text
node scripts/run-framework.mjs dev --port 5173
```

打开 `http://127.0.0.1:5173/`。本地预览使用测试登录身份；正式版通过 Sites 的私人访问进行身份识别。手机安装需要打开正式版的 HTTPS 地址。

## 手机安装

- iPhone：在 Safari 中打开正式版，点“分享”→“添加到主屏幕”。
- Android：在 Chrome 中打开正式版，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。
- 安装后从“有余”图标打开；需要联网读取和保存账本。关闭页面后，站内提醒不会变成系统推送。

产品官网在 `http://127.0.0.1:5173/intro`，主页和页尾的“体验有余”会打开原有演示账本。官网位于独立路由，账本首页和数据接口保持原样。

官网复用 `public` 中的叶片 LOGO、账户图标和项目现有真实界面截图。`public/marketing` 中的两张氛围图由内置 ImageGen 生成并压缩为 WebP：首屏提示词为“暖白背景、少量翡翠绿与嫩叶绿的半透明叶片、柔和晨光、大面积留白；不要文字、LOGO、手机或界面”，生活方式图提示词为“自然光下的中国大学校园书桌、合上的笔记本与一杯水、窗外绿意、纪实摄影；不要人物、可读文字、品牌或界面”。所有产品画面均来自真实截图，网页独立叠加。

预览手机布局：在 Edge 或 Chrome 中打开上述地址，按 `F12`，再按 `Ctrl+Shift+M` 打开设备工具栏，选择 `iPhone 13` 或设为 `390 × 844`，刷新页面即可查看。关闭设备工具栏可返回电脑布局。
